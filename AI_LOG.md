## AI Usage Log

AI tools were used during the development of the Northline Roofing Cost Estimator as a development and problem-solving assistant.

The final implementation was reviewed, tested, and adapted to match the assignment requirements.

---

## 1. Project Planning

AI was used to help break the assignment into smaller development tasks and plan the overall application architecture.

Areas included:

- Public roofing estimator flow
- Owner dashboard
- Backend API structure
- MongoDB data organization
- Authentication
- Estimate calculation
- Lead capture
- Deployment planning

---

## 2. Frontend Development

AI assistance was used during the development of the React frontend.

Areas included:

- Multi-step estimator UI
- Form handling
- Dynamic questions
- Material selection
- Roof pitch selection
- Roof layer selection
- Number of stories
- Estimate result display
- Lead capture form
- Owner dashboard UI
- Responsive styling

The generated suggestions were reviewed and modified where necessary to fit the application.

---

## 3. Backend Development

AI was used as a development assistant while implementing the Node.js and Express backend.

Areas included:

- Express server setup
- REST API design
- Route organization
- Controller structure
- Middleware
- Authentication
- JWT handling
- Server-side estimate calculation
- Lead management
- Error handling

The backend implementation was tested against the frontend requirements.

---

## 4. Database

AI was used to assist with MongoDB schema and data structure planning.

The database was used for information such as:

- Estimator questions
- Roofing materials
- Roof pitches
- Roof layers
- Stories
- Pricing/configuration data
- Leads
- Owner/user information

The final database structure was reviewed according to the application's requirements.

---

## 5. Estimate Calculation

AI was used to help reason about the roofing estimate calculation logic.

The calculation considers the selected estimator inputs and produces an estimated price range.

The calculation is performed on the server side so that pricing logic is not dependent on frontend calculations.

The final calculation logic was reviewed and tested manually.

---

## 6. Authentication and Security

AI assistance was used for implementing and reviewing authentication-related functionality.

Areas included:

- JWT authentication
- Password handling
- Protected owner routes
- Authorization middleware
- Environment variables
- API security considerations

Sensitive configuration values were kept outside the source code using environment variables.

---

## 7. Debugging

AI was used as a debugging assistant during development.

It helped investigate issues related to:

- API requests
- React components
- Express routes
- MongoDB connections
- Authentication
- Form state
- Dynamic estimator questions
- Estimate calculations
- Frontend/backend communication

Solutions were tested manually before being included in the project.

## 8. Documentation

AI was used to assist with improving and organizing project documentation.

## 10. Summary

AI was used as a development assistant for planning, coding guidance, debugging, documentation, and problem solving.

The final application was implemented, reviewed, and tested manually to ensure that it satisfies the requirements of the Northline Roofing Cost Estimator assignment.
